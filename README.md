# Research Paper Publisher Tracker

A browser-only publication tracker for TGDetect research in AI, machine learning, data science, and cybersecurity. It covers 15 publisher/platform websites and 18 venues, with official source links, formatting links, local watchlists, calendar exports, and live countdowns.

Open `index.html` directly or deploy the repository as a static site on Vercel. No backend, database, API keys, installation step, or build command is required. See [DEPLOY.md](DEPLOY.md) for deployment settings.

The browser refreshes the bundled deadline data and selected community AI conference feeds while the page is visible. Countdown clocks update locally. Official publisher pages remain the authority; the interface separates community updates, rolling submissions, closed cycles, and unannounced deadlines. A static website cannot check every publisher continuously while nobody has it open.

Publication dates and sources were last researched on 6 October 2026. Users should check the linked official call before submitting, especially abstract-registration deadlines, time zones, and revised calls.

Only public website files are included. This repository excludes project telemetry, datasets, model checkpoints, credentials, downloaded papers, and private research documents.

Third-party notices are recorded in [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt).
