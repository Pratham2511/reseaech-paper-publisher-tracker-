What updates automatically

The clock and countdowns refresh every 30 seconds. While this page is open, it reloads hosted venue data and four community AI conference feeds every 15 minutes, and checks again when you return to the tab. A failed check keeps the last available data and its timestamp.

Community feed updates are candidates to verify, displayed separately from official dates. Publisher pages are not automatically rechecked. The official check date tells you how old the research is; a feed refresh does not change it.

Watchlists stay in this browser. Calendar export includes paper and registration dates with a seven-day reminder. Calendar imports are snapshots; re-export after date changes. This page does not send notifications while closed.

Share a small static site

This site is HTML, CSS and JavaScript. Host the prepared folder on Vercel to share one URL with friends. There are no server functions, database, API keys or installation steps.

Official template links stay on the publishers' sites. arXiv hosts moderated preprints and provides no peer review or universal manuscript template. Conference page limits may require a shorter submission version of your research.

The public package contains only venue research. Project dossiers, model files and downloaded reference papers remain in your local workspace.
